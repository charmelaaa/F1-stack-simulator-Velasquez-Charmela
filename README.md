Activity Description

This activity introduces HTML, CSS, Bootstrap, JavaScript, and jQuery through a Stack Simulator Web App. It demonstrates how a stack follows the Last In, First Out (LIFO) principle and how stack data can be displayed on a web page.


## Week 12 - Stack Simulator

This project is a simple Stack Simulator using HTML, CSS, JavaScript, and jQuery.

It demonstrates the Push, Pop, Peek, and Clear operations of a Stack data structure using the Last In, First Out (LIFO) principle.
